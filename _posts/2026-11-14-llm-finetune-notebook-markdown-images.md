**한 줄 요약:** 답변과 산출물을 마크다운으로 보기 좋게 보여 주고, 채팅에 스크린샷·이미지를 여러 장 첨부해 Gemini에 함께 물어볼 수 있게 했습니다.

| 기능 | 내용 |
|---|---|
| 마크다운 보기 | 제목, 굵게, 목록, 표, 코드, 인용, 링크. 산출물은 「📝 원문 보기」로 전환, 복사·내려받기는 항상 원문 |
| 이미지 첨부 | 📷 버튼(여러 장 선택), 붙여넣기(Ctrl+V), PC는 끌어놓기. 최대 4장 |
| 자동 축소 | 올리기 전에 브라우저에서 줄여 폰에서도 Vercel 요청 한도(4.5MB) 안에 들어옴 (17MB 원본 → 약 370KB) |
| 질문 없이 전송 | 이미지만 보내면 "이 이미지를 설명해 주세요"로 질문 |
| 저장 | 대화 기록에는 작은 미리보기만 저장(저장 공간 절약) |

| 저장소 | 커밋 |
|---|---|
| llm-finetune-notebook | 8dec478 |

**안전:** 마크다운 속 HTML(script 등)은 모두 글자로 바꿔 실행되지 않게 했습니다.

**미확인:** 배포 후 실제 Gemini가 이미지를 읽는 것, 실제 폰 카메라·갤러리 선택.

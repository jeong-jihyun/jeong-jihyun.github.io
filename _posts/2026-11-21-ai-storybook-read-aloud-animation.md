## 어떻게 동작하나
- 목소리: 동화 본문을 쪽마다 MP3로 만들고 문장별 시간을 함께 저장합니다. 본문이 바뀌면 GitHub Actions가 바뀐 쪽만 다시 만듭니다.
- 그림 움직임: 확대·이동·둥실·살랑, 반짝이/눈송이(최대 30개). 모든 움직임은 "지금 재생 위치(초)"로만 계산해서, 멈추면 멈추고 되감아도 같은 모습입니다.
- 자막: 목소리가 읽는 문장을 형광펜으로 표시합니다.
- 설정: 목소리 켜기/끄기, 자막, 속도(0.8·1·1.25배), 움직임 줄이기. 기억됩니다. 앱이 뒤로 가면 자동으로 멈춥니다.
- 음성이 아직 없으면 "준비중"으로 표시하고 소리 없이 움직임·자막만 동작합니다.

## 확인한 것
- 움직임·자막 계산 시험 12개 통과
- 실제 브라우저(세로·가로)에서: 재생 → 일시정지 시 정지 → 모션 줄이기 시 정지 화면 → 속도 변경 → 다음 쪽 자동 넘김
- 실제로 생성된 음성으로: 첫 문장 → 둘째 문장 형광펜 이동 → 다음 쪽 자동 넘김

웹페이지에서 선택한 글자나 현재 페이지 정보를 내가 정한 웹훅 주소로 보내는 크롬 확장 프로그램을 GitHub에 올렸습니다.

| 저장소 | 바뀐 내용 | 커밋 |
|---|---|---|
| [webhook-trigger-extension](https://github.com/jeong-jihyun/webhook-trigger-extension) | 첫 버전 올림 (파일 7개) | d27843f |

## 할 수 있는 일

| 기능 | 설명 |
|---|---|
| 우클릭 전송 | 글자를 드래그해 우클릭하면 웹훅으로 보냄 |
| 페이지 정보 전송 | 현재 페이지 제목과 주소를 보냄 |
| 키워드 자동 감지 | 페이지에 "할인" 같은 단어가 보이면 자동으로 보냄 |
| 30분 주기 신호 | 팝업에서 켜고 끌 수 있음 |
| 전송 결과 표시 | 아이콘 배지로 성공(✓)과 실패(✗)를 알려 줌 |

## 쓰는 법

1. 크롬에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. "압축해제된 확장 프로그램을 로드합니다"로 폴더를 고릅니다.
3. 아이콘을 눌러 웹훅 주소를 저장하고 "테스트 전송"으로 확인합니다.

## 미확인

- 크롬 웹 스토어 등록은 하지 않았습니다. 지금은 개발자 모드로만 쓸 수 있습니다.

## 들어간 기능

| 구분 | 내용 |
|---|---|
| 되묻기 | 사업 유형·내 지위·사업 단계·사전 요청 여부를 보기 버튼으로 확인 (건너뛰기·바로 분석 가능) |
| 분석 결과 | 결론 → 사실관계·추가 확인 → 쟁점·유불리 → 법령·판례 원문 링크 → 대응 방법·위험 → 다음 행동·추천 서류 |
| 안전장치 | 앱에 없는 법령·판례 인용은 자동 제외, AI 연결 실패 시 기본 분석으로 대체 |
| 개인정보 | 주민등록번호·휴대폰 번호 자동 가림, 상담 기록은 기기에만 저장 |
| 편의 | 이어서 질문, 결과 복사, 상담 기록 삭제, 결과가 오면 결론부터 표시 |

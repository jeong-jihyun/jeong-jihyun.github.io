동화숲 앱에 **판매 기능**을 붙였습니다. 보호자가 가입하고, 보호자 PIN을 확인한 뒤 결제하면 서버가 영수증을 검증하고 내 서재에 책을 넣어 줍니다. 지금은 돈이 나가지 않는 테스트 결제로 동작합니다.

## 만든 것

| 구분 | 내용 |
|---|---|
| 회원 | 보호자 가입·로그인·로그아웃·정보 수정·탈퇴 |
| 보호자 확인 | PIN 4자리, 5번 틀리면 5분 잠금, 결제·정보 변경 전 확인 |
| 주문 | 가격은 서버가 계산, 두 번 눌러도 주문 1건 |
| 결제 검증 | 영수증을 서버가 확인, 재사용·위조·남의 영수증 거절 |
| 결제 방식 | 테스트 결제 사용 중, 구글 플레이·애플 검증 코드 준비 |
| 내 서재 | 산 책만 끝까지 읽기 |
| DB | Supabase 무료(서울), 외부 접근 잠금 |

## 확인한 것
- 서버 테스트 67개 통과
- 가입 → PIN → 테스트 결제 → 내 서재 → 끝까지 읽기 흐름을 폰 크기 화면으로 확인

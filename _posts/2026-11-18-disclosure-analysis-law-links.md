**한 줄 요약:** 공시 분석 사이트의 공시 카드와 '눈여겨볼 신호'에 관련 법령 바로가기를 붙였고, 임원 현황 글자가 깨지던 문제를 고쳤습니다. 법령 링크를 누르면 국가법령정보센터의 해당 조문으로 이동합니다.

| 공시 유형 | 연결되는 법령 |
|---|---|
| 유상증자 | 상법 제416조, 자본시장법 제165조의6 |
| 메자닌(전환사채 등) | 상법 제513조·제516조의2, 자본시장법 제165조의10 |
| 감자 | 상법 제438조 |
| 횡령·배임 | 형법 제355조, 특정경제범죄법 제3조 |
| 상장 위험 / 불성실공시 | 자본시장법 제390조 / 제391조 |
| 소송·손실·담보 | 자본시장법 제161조 |
| 최대주주·경영권 | 자본시장법 제147조 |

- 인증키 없이 국가법령정보센터의 공식 주소 형식으로 연결해, 비용과 설정이 필요 없습니다.

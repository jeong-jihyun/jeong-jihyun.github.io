## 새로 된 것

| 항목 | 내용 |
|---|---|
| 테마 | 파스텔·다크·빈티지·테라코타 추가 (모두 8개). 다크는 종이 전체가 어둡고, 빈티지는 크림색 종이 |
| 내 색 고르기 | 메인색 하나만 고르면 연한 칸 색이 자동으로 맞춰짐. 너무 밝은 색이면 글자·선이 자동으로 진해짐 |
| 글꼴 | 나눔고딕·나눔명조·나눔바른고딕·나눔스퀘어라운드·나눔손글씨 펜 (모두 상업 이용 가능) |
| 표지 글 | 제목(40자)·이름(30자)·한 줄 다짐(60자) |

## 확인한 것

- 테스트 통과: 엔진·서버 127개, 화면 18개
- 서버 배포 성공, 글꼴 5종 모두 설치 확인
- 화면 배포 완료: [플래너 만들기 화면](https://goodnotes-digital-planner.vercel.app/#/create)

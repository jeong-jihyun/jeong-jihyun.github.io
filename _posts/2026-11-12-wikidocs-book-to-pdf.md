위키독스 책 주소를 넣으면 모든 페이지를 모아 PDF 한 권으로 만들어 주는 **서버 + 모바일 앱(React Native)** 을 만들어 올렸습니다. 무거운 작업은 서버가 하고, 앱에서는 설정 입력, 구글 드라이브 폴더 선택, 진행 확인, PDF 받기를 합니다.

| 저장소 | 바뀐 내용 | 커밋 |
|---|---|---|
| [wikidocs-book-to-pdf](https://github.com/jeong-jihyun/wikidocs-book-to-pdf) | 서버(FastAPI), 앱(Expo), Render 배포 설정, APK 자동 빌드, 설치 안내서 | fd7767f |

## 단계별로 어디에 있나

| 단계 | 내용 | 위치 |
|---|---|---|
| 1 | 패키지 설치 | server/requirements.txt, Dockerfile |
| 2 | 설정값 입력 | 앱 설정 화면 → server/app/step2_config.py |
| 3 | 크롤러·PDF 변환 | server/app/step3_*.py |
| 4 | 실행·진행 표시 | server/app/step4_runner.py, 앱 진행 화면 |
| 5 | PDF 받기 | 앱 결과 화면 |
| 6 | 구글 드라이브 저장 | server/app/step6_drive.py, 앱 폴더 선택 |

## 직접 확인한 것

- 실제 위키독스 페이지 구조로 목차 93개와 3단계 계층을 읽는 것
- 가짜 위키독스 서버로 서버 전체 시험 9개 통과 (수집 → 변환 → 병합 → 내려받기, 취소, 오류 처리)
- 앱 코드 타입 검사와 안드로이드 JS 번들 만들기, 앱과 서버가 주고받는 데이터 모양 일치
- PDF 한글·표·코드·이모지·목차·쪽 번호를 이미지로 확인

## 확인하지 못한 것

- Render 서버에 실제로 올라가는지 (Docker 빌드는 이 작업 환경에서 불가)
- 실제 구글 로그인과 드라이브 저장 (구글 클라우드 설정이 필요)
- APK 빌드 결과와 폰에서의 화면·설치 (GitHub Actions 에서 처음 돌려 봐야 함)
- Render 서버에서 위키독스에 접속이 막히지 않는지

본인이 열람할 수 있는 공개 책을 개인 소장용으로 변환하는 용도입니다. 저작권은 원저자에게 있습니다.

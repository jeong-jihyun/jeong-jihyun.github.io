## 한 줄 요약

카카오 로그인을 한 번만 해 두면, 이후에는 주소 하나로 내 카카오톡에 메시지를 보내는 중계 앱을 만들어 GitHub와 Vercel에 올렸습니다. 클라우드 작업 환경은 카카오 서버에 직접 접속할 수 없어서 중계 방식으로 만들었습니다.

## 반영 내용

| 저장소 | 바뀐 내용 | 커밋 |
|---|---|---|
| [kakao-message-app](https://github.com/jeong-jihyun/kakao-message-app) | 로그인 토큰을 비공개 저장소에 보관, 만료 시 자동 갱신, 보내기 주소(/api/notify) 추가, 관리 키로 보호 | 65d3e6f |

## 동작 방식

| 단계 | 내용 |
|---|---|
| 최초 인증 (1번) | 첫 화면에서 관리 키 입력 후 카카오 로그인·동의 → 토큰 저장 |
| 계속 사용 | /api/notify 호출 → 저장된 토큰으로 전송 |
| 토큰 만료 | 액세스 토큰(약 6시간)이 끝나면 리프레시 토큰으로 자동 갱신하고 새 토큰 저장 |
| 재인증 | 리프레시 토큰(약 60일)이 끝났을 때만 필요 |

## 확인한 것

| 항목 | 결과 |
|---|---|
| 가짜 카카오 서버로 26가지 시나리오 (최초 인증, 자동 갱신, 서버 401 재시도, 갱신 실패, 잘못된 키, 동시 호출) | 모두 통과 |
| Vercel 배포 | 완료 |
| 배포된 주소 호출 | 인증 전 "인증 필요" 응답 확인 |

## 미확인

- 실제 카카오 로그인, 토큰 발급, 실제 메시지 전송은 아직 확인하지 못했습니다.
- Vercel에 카카오 REST API 키와 클라이언트 시크릿을 넣는 설정이 남아 있습니다.
- 앞서 나온 "Bad client credentials" 오류의 원인은 아직 확정하지 못했습니다. 새 화면은 오류 코드를 함께 보여 줍니다.

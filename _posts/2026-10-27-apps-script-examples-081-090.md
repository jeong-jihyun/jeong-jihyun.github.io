AI 없이 구글 기본 기능만 쓰는 "일상 업무 자동화 시리즈"의 예제 081~090번 10개가 저장소에 추가되었습니다.

| 번호 | 제목 | 하는 일 |
|---|---|---|
| 081 | 시트 칸에 드롭다운(고르기) 목록 만들기 | 드롭다운으로 고르기 |
| 082 | 매주 월요일 시트를 통째로 백업 복사하기 | 매주 자동 백업 복사 |
| 083 | 오늘 받은 메일 제목을 저녁에 한 통으로 받기 | 오늘 받은 메일 저녁 요약 |
| 084 | 오늘 캘린더 일정을 아침에 메일로 받기 | 오늘 일정 아침 메일 |
| 085 | 드라이브 폴더에서 오래 안 쓴 파일 찾아 목록 만들기 | 오래된 파일 목록 |
| 086 | 시트 명단으로 사람마다 안내문 문서 만들기 | 명단으로 안내문 만들기 |
| 087 | 시트의 전화번호를 010-1234-5678 모양으로 맞추기 | 전화번호 모양 통일 |
| 088 | 구글 문서 맨 위에 목차 자동으로 넣기 | 문서 목차 자동 삽입 |
| 089 | 매일 합계 숫자를 '기록' 탭에 한 줄씩 쌓기 | 매일 합계 기록 쌓기 |
| 090 | 이번 달 캘린더 일정을 시트에 목록으로 뽑기 | 이번 달 일정 표로 뽑기 |

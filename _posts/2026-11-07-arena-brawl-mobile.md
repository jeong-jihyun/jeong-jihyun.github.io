아레나 슈터 프로토타입 `arena-brawl-mobile`이 11월 6일~7일에 올라갔습니다. 처음에는 브라우저에서 하는 데모(HTML)였고, 이를 React Native + TypeScript 게임으로 바꿨습니다. 오리지널 프로토타입이며 기존 게임의 캐릭터·그림·상표를 따라 만들지 않았다고 README에 적혀 있습니다.

저장소: https://github.com/jeong-jihyun/arena-brawl-mobile

## 무엇이 들어 있나

| 구분 | 내용 |
|---|---|
| 기술 | Expo SDK 54, React Native 0.81, React 19, TypeScript(엄격 모드), Shopify Skia 그림판 렌더링 |
| 조작 | 가상 조이스틱으로 이동, 공격 버튼 누르고 있으면 연속 발사 |
| 게임 규칙 | 가로 화면 아레나, 적이 쫓아오고 멀리서 쏨, 장애물 충돌, 투사체, 체력·점수, 범위 특수 공격과 재사용 대기, 승리·패배·다시 시작 |
| 구조 | 게임 엔진(`src/game`), 고정 간격 시계(`FixedStepClock`), 충돌 계산(`domain/physics/collision`), 화면 부품(조이스틱·버튼·캔버스) |
| 검사 | 타입 검사와 단위 테스트(엔진, 고정 간격 시계, 충돌 3개 파일), GitHub Actions로 푸시마다 자동 실행 |
| 안드로이드 빌드 | 자동 빌드가 Expo 설정 확인 → 자바스크립트 묶음 확인 → 안드로이드 프로젝트 생성 → APK 빌드 → 에뮬레이터 실행·화면 캡처까지 시도하고 결과물을 올림 |

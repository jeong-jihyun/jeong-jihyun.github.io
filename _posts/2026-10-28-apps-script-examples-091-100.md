AI 없이 구글 기본 기능만 쓰는 "일상 업무 자동화 시리즈"의 예제 091~100번 10개가 저장소에 추가되어, 전체가 100개가 되었습니다.

| 번호 | 제목 |
|---|---|
| 091 | 시트에서 고른 칸에 오늘 날짜 한 번에 넣기 |
| 092 | 시트의 비어 있는 줄 한 번에 지우기 |
| 093 | 시트 글자 앞뒤의 쓸데없는 빈칸(공백) 지우기 |
| 094 | 별표 표시한 메일을 시트에 목록으로 뽑기 |
| 095 | 구글 문서에서 여러 단어를 한 번에 바꾸기 |
| 096 | 시트에 적은 이름대로 드라이브 폴더 여러 개 만들기 |
| 097 | 시트에서 '완료'인 줄 숨기고 다시 보이게 하기 |
| 098 | 시트 항목별 개수를 세어 '요약' 탭 만들기 |
| 099 | 휴가 중 자동 답장 켜고 끄기 |
| 100 | 시트 제목줄 고정하고 보기 좋게 서식 한 번에 맞추기 |

- 저장소: [jeong-jihyun/google-app-script](https://github.com/jeong-jihyun/google-app-script)
- 커밋: 58fe637
- 시리즈: 일상 자동화 시리즈 1회차 (3차)
- 모든 예제에 코드(code.gs)와 따라 하기 설명(README.md)이 있고, API 키는 필요 없습니다.

구글·카카오·네이버 간편 로그인 버튼을 붙이고, 로그인과 회원가입 화면을 나눴습니다.

| 바뀐 내용 | 설명 |
|---|---|
| 간편 로그인 | 구글·카카오·네이버 버튼 (Supabase 로그인 설정 연결) |
| 네이버 | 네이버는 응답 형식이 달라 Supabase Edge Function으로 중간 변환 |
| 로그인 / 회원가입 탭 | 회원가입은 이름 + 이용 동의가 있어야 완료 |
| 이용 동의 확인 | 처음 소셜 로그인한 사람에게도 이름·동의를 한 번 받음 |
| 처음으로 버튼 | 로그인 화면에서 홈으로 바로 돌아감 |
| 자료확인일 | 법령·판례 자료 확인일이 무엇인지 설명 문구 추가 |

- 저장소: [redevelopment-dispute-platform](https://github.com/jeong-jihyun/redevelopment-dispute-platform) 커밋 `ee5dc7b`
- 배포: Vercel 운영 배포 완료, 로그인 화면에 세 버튼이 보이는 것까지 확인

**미확인**
- 실제 구글·카카오·네이버 계정으로 끝까지 로그인되는지는 아직 시험하지 못했습니다.
- 구글 동의 화면이 '테스트 모드'라 등록된 테스트 사용자만 로그인됩니다.

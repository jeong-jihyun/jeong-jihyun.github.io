글을 발행해 놓고 색인이 됐는지, 검색에 노출되는지 확인하는 걸 자꾸 잊어버립니다. 그래서 글 제목과 발행 시각만 넣으면 네이버 캘린더에 확인 일정이 한 번에 들어가는 작은 웹앱을 만들었습니다.

## 하는 일

- 발행 일정 등록
- 발행 1일 뒤: 검색 색인 확인
- 발행 7일 뒤: 검색 노출 확인
- 발행 14일 뒤: 성과 점검

글을 자동으로 올리지는 않습니다. 확인할 시점을 알려 주는 것까지만 합니다.

## 만든 과정에서 알게 된 것

처음에는 네이버 검색 API로 키워드 분석기를 만들려 했는데, 기존 네이버 개발자센터의 등록 화면에는 검색 API가 더 이상 선택지에 없었습니다. 새 서비스인 NAVER API HUB로 옮겨 가는 중이었고, 거기서는 결제수단 등록이 필요했습니다. 그래서 방향을 바꿔, 개발자센터에 남아 있던 네이버 로그인과 캘린더 API로 이 앱을 만들었습니다.

## 쓰는 법

1. 네이버 개발자센터에서 앱을 등록하고 사용 API로 네이버 로그인과 캘린더를 선택합니다.
2. 받은 Client ID와 Secret을 `.env.local`에 넣습니다.
3. `npm install`, `npm run dev`로 실행하고 로그인한 뒤 글 정보를 입력합니다.

키는 서버에서만 쓰이고 저장소에는 올라가지 않습니다.

**한 줄 요약**: 동화숲 사이트가 임시 저장소를 쓰고 있어서 재배포하면 가입한 계정이 사라졌습니다. Supabase DB를 Vercel에 연결해 계정이 남도록 고쳤습니다.

## 무엇이 문제였나

| 증상 | 원인 |
|---|---|
| 가입했는데 나중에 로그인이 안 됨 | 실제 사이트에 DB 주소가 없어서, 서버가 임시 저장소(메모리)를 사용. 재배포·서버 교체 때마다 비워짐 |

## 무엇을 바꿨나

| 항목 | 내용 | 커밋 |
|---|---|---|
| 서버 코드 | `DATABASE_URL` 또는 Vercel 연동의 `POSTGRES_URL`을 읽도록 수정, Supabase 접속에 맞게 SSL 처리 | 6ccedb9 |
| 로그인 서명키 | 연동으로 들어오는 `SUPABASE_JWT_SECRET`을 우선 사용 (DB 비밀번호가 바뀌어도 로그인 유지) | 6ccedb9 |
| Vercel 설정 | Supabase 공식 연동으로 DB 주소·키가 자동으로 들어감 (비밀번호는 아무도 직접 다루지 않음) | - |
| 테스트 | DB 주소 처리 테스트 2개 추가 (총 87개 통과) | 6ccedb9 |

## 확인한 것

- 배포 상태 READY, 사이트 `health`가 `postgres`로 표시됨
- 서버 오류 없음, Supabase에 서버의 연결이 잡혀 있음
- 동화 목록이 정상 응답

## 아직 확인하지 못한 것

- 실제 가입 → 재배포 → 같은 계정으로 로그인 (가입 비밀번호는 사용자가 직접 입력해야 해서, 사용자 확인 대기 중)
- 기존에 가입했던 계정은 임시 저장소에 있었기 때문에 복구할 수 없습니다. 한 번 더 가입이 필요합니다.
